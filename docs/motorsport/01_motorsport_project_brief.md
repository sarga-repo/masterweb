# Sarga Motorsport Dedicated Website — Project Brief

## Background

Sarga.co remains the group gateway. Sarga Motorsport will become a dedicated website with its own brand experience and frontend, while sharing the same Strapi CMS and technical stack.

## Objective

Create a premium, international-standard Sarga Motorsport website that presents the brand as Indonesia's leading motorsport ecosystem: high-energy, professional, immersive, and commercially ready for events, campaigns, media, and ticketing journeys.

Sarga Motorsport is **multi-discipline**. Its public experience must represent
both four-wheel and two-wheel competition—including touring/formula/rally cars
and circuit, road-racing, or other sanctioned motorcycle categories—without
making either discipline feel secondary.

## Strategic role

The site should function as:

- a brand destination for Sarga Motorsport;
- a campaign hub for racing and lifestyle events;
- an event information and ticketing journey front door;
- a media/news platform for motorsport content;
- a scalable frontend for future racing series, venues, sponsors, and community programs.
- an inclusive home for car and motorcycle racing series, athletes, teams, and fans.

## Relationship with Sarga.co gateway

- Sarga.co keeps the group/corporate ecosystem overview.
- Sarga Motorsport has a dedicated frontend.
- Gateway ecosystem cards, motorsport news teasers, and motorsport ticket CTAs should link to the dedicated motorsport site.
- CMS content should be shared, not manually duplicated.

## Non-goals

- No internal payment processing.
- No public user account/login.
- No internal ticketing engine.
- No separate CMS in the first phase.
- No visual copying from Sarga.co gateway. The motorsport site must follow the Sarga Motorsport brand playbook.

## Success criteria

- Motorsport frontend has a distinct premium visual identity.
- Car and motorcycle racing are both visible in imagery, event taxonomy, editorial content, and discovery journeys.
- Site content can be managed from the shared Strapi CMS.
- Gateway and motorsport sites can display the same event/news data in different layouts.
- Docker Compose runs both frontends and CMS locally.
- The implementation remains maintainable in one repository.
