# Sarga Motorsport Brand Translation for Web

## Source

Primary source: `reference/source-pdfs/sarga_motorsport_brand_playbook.pdf`.

## Brand story

Sarga Motorsport is described as the ultimate powerhouse of Indonesian motorsport, building the nation's premier 360° racing ecosystem. The brand focuses on amplification: transforming the raw adrenaline of the track into a world-class spectacle through professional racing standards and lifestyle entertainment.

## Brand persona

The brand persona is **The Adrenaline Alchemist**.

Keywords:

- Dynamic
- Captivating
- Intense
- High-energy
- Vibrant
- Electrifying
- Bold
- Professional
- Unmatched in scale

## Web design translation

The website should feel like:

- a high-performance racing media platform;
- a premium event and ticketing destination;
- an editorial motorsport experience;
- fast, cinematic, and highly polished.

## Visual system

### Color palette

```text
Apex Crimson       #E8192C
Ignition Orange    #FF6B00
Electric Yellow    #F5C800
Slipstream Teal    #00C4CC
Draftline Blue     #0033A0
Charcoal Black     #1B1B1B
Warm White         #FFF9EE
```

Use dark backgrounds as the default canvas, especially charcoal/black and draftline blue gradients. Use crimson and orange for energy, CTAs, hover states, active tabs, accent lines, and motion-inspired treatments. Use teal/yellow sparingly for category labels, status chips, or data highlights.

### Typography

- Display: Owners Wide, with fallbacks to wide/extended sans-serif families.
- Body: Noto Sans.

Implementation note: do not include licensed font files unless the team owns webfont rights. Configure CSS variables and fallback stacks so fonts can be added later.

### Photography style

Use motorsport imagery with:

- motion blur;
- speed trails;
- track/circuit atmosphere;
- cockpit/driver closeups;
- crowd and lifestyle event energy;
- night lights, smoke, friction, asphalt, heat;
- professional racing/event photography.
- a deliberate balance of car and motorcycle racing subjects across heroes,
  event cards, editorial modules, and gallery rails;
- motorcycle-specific perspectives such as rider lean angle, knee-down cornering,
  helmet/visor detail, pit-lane preparation, and pack racing.

Do not let the overall media library imply that Sarga Motorsport is a car-only
brand. Avoid token inclusion: two-wheel imagery should recur naturally across
the experience rather than appearing in a single isolated card.

### Graphics

Use:

- racing stripe motifs;
- slanted blocks;
- track-line patterns;
- speed blur overlays;
- gradient heat maps;
- subtle grid/telemetry elements;
- split-screen editorial compositions.

Avoid making the site look like the Sarga.co gateway. The gateway is group/corporate; Motorsport must be more intense, kinetic, and campaign-driven.

## Logo usage

Use files in:

```text
assets/brand/motorsport/logos/
```

Rules:

- Minimum digital width: 140px.
- Preserve clear space.
- Use full-color logo on light backgrounds.
- Use all-white logo on red/orange backgrounds if available.
- Use inverse/full-color variant on dark backgrounds where legible.
- Do not place logo over busy image areas without a protective overlay.

## Tone of voice

Use active, powerful language:

- "Where friction creates fire."
- "Racing, amplified."
- "Witness the energy. Live the intensity."
- "The track becomes a spectacle."

Use this style for hero copy, campaign cards, event pages, and social-friendly snippets.
