# Sarga.co Gateway — Static Home Baseline

Approval-gate implementation for the Sarga.co gateway redesign. This app is
intentionally static and CMS-free; `frontend-gateway-onepage/` remains the
reference and source asset project.

## Local development

```bash
pnpm install
pnpm dev
```

Open `http://localhost:3005`.

## Verification

```bash
pnpm typecheck
pnpm lint
pnpm build
```
