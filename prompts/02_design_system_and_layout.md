Task: implement global design system and layout components.

Requirements:

- Read `docs/07_design_system.md`.
- Read `docs/12_visual_reference_guideline.md`.
- Review page 7 of `reference/source-pdfs/sarga_website_preview.pdf` for the binding brand foundation. Review pages 1-5 only as examples of one possible implementation.
- Add CSS variables/design tokens.
- Build reusable components:
  - Header
  - Mobile navigation drawer
  - Footer
  - Button
  - SectionContainer
  - Card
  - Badge
  - PillTabs
  - Input/Textarea/Select
- Header navigation:
  - About
  - 360° Ecosystem
  - News & Publication
  - Careers
  - Get in Touch
  - Ticket Hub
- Footer columns:
  - Ecosystem Map
  - Publications
  - Newsletter
- Use responsive behavior for mobile/tablet/desktop.
- Use accessible semantic HTML.

Acceptance criteria:

- Header and footer appear on all pages.
- Mobile nav works.
- Buttons and cards form a distinctive, coherent premium system using the approved Sarga brand foundation.
- The result demonstrates original composition and does not simply reproduce the preview's header, footer, cards, or section layouts.
- No CMS dependency yet.

Include a reusable Logo component with `default` and `reverse` variants based on the provided assets.

Design reference rule:

- Use page 7 for colors, Zalando Sans Expanded headings, Plus Jakarta Sans body/interface text, racing graphics, and cinematic sport/entertainment imagery.
- Use pages 1-5 for mood and quality calibration only. Create an original header, footer, spacing system, component language, and responsive composition at a premium international standard.
- Brand graphics should be recognizable but may be scaled, layered, cropped, animated, or recomposed purposefully; avoid decorative overuse.
