Execute this phase only.

Read:

- `docs/motorsport/02_motorsport_brand_translation.md`
- `docs/motorsport/04_motorsport_design_system.md`
- `reference/source-pdfs/sarga_motorsport_brand_playbook.pdf`

Tasks:

1. Implement Sarga Motorsport design tokens.
2. Configure Tailwind theme values for colors, typography, spacing, and effects.
3. Add reusable components:
   - MotorsportHeader
   - MotorsportFooter
   - MotorsportHero
   - EventFeatureCard
   - EventListCard
   - TicketCtaPanel
   - NewsCard
   - ExperiencePillarCard
   - PartnerLogoStrip
   - GalleryRail
   - CountdownBadge
   - StatusChip
   - SectionHeader
4. Add reduced-motion-safe interaction patterns.
5. Ensure logo usage follows brand rules.

Rules:

- Premium international-standard frontend UI.
- Dark, kinetic, cinematic motorsport direction.
- Represent both car and motorcycle racing in showcase media and component states; do not present Sarga Motorsport as car-only.
- Do not reuse gateway design system except neutral utilities.

Acceptance criteria:

- Design system components are reusable and typed.
- Components support CMS-driven content.
- No hardcoded content deep inside generic components.

Do not continue to the next phase.
