# 05 - Motorsport Homepage

Execute this phase only.

Read:

- `docs/motorsport/03_motorsport_sitemap_page_specs.md`
- `docs/motorsport/04_motorsport_design_system.md`
- `reference/source-pdfs/sarga_motorsport_brand_playbook.pdf`
- `.agents/skills/`

Build a premium Sarga Motorsport homepage.

Required sections:

1. Header/navigation
2. Cinematic hero
3. Featured event/ticket CTA
4. Brand story / 360° racing ecosystem intro
5. Upcoming events
6. Experience pillars
7. News/media highlights
8. Gallery strip
9. Partner/sponsor strip
10. Newsletter/contact CTA
11. Footer

Rules:

- Use CMS-ready data structures and graceful fallback placeholder content.
- Use motorsport visual identity, not gateway visual identity.
- Make it responsive across desktop, tablet, and mobile.
- Use premium-frontend-ui skill guidance.
- Balance car and motorcycle racing across featured events, hero/gallery imagery, and editorial content.

Acceptance criteria:

- Homepage feels distinct from Sarga.co gateway.
- Primary ticket CTA works as redirect/deep link placeholder.
- Page structure is ready for CMS integration.

Do not continue to the next phase.
